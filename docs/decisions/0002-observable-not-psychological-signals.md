# 0002：只保留可觀察訊號，不產生心理分數

- Status：Accepted
- Date：2026-08-30

## Context

語音和影像可以產生可量化資訊，但這些資訊容易被誤讀為人格、誠實、情緒或能力判定。

## Decision

報告只呈現與逐字稿連結的具體談判行為，以及本局的可觀察 geometry／delivery aggregate。禁止情緒、欺瞞、自信、人格、雇主評分與招募篩選推論。

## Alternatives

- 以模型產生情緒或自信分數。
- 將訊號轉成員工績效排序。
- 保存原始影像或音訊供日後重算。

## Consequences

產品說明與貢獻審查必須拒絕相關需求。可觀察訊號需要附限制說明，不能被包裝成心理或 HR 結論。
